### [DXR Path Tracer](https://github.com/WestMinsu/DXRPathTracer)

A real-time path tracer implemented with DirectX 12 and DirectX Raytracing.

- PBR path tracing, multi-bounce, NEE, MIS, and GGX BRDF sampling.
- Temporal reconstruction, history validation, disocclusion handling, and À-Trous filtering.
- Dynamic scenes, skeletal animation, GPU profiling, and shader optimization.

**Tech:** C++, DirectX 12, DXR, HLSL

### [WestEngine](https://github.com/WestMinsu/WestEngine)

A DirectX 12 / Vulkan dual-backend real-time rendering engine built around a shared RHI.

- Unified RHI, bindless resources, Render Graph, and GPU-driven rendering.
- Deferred PBR pipeline and a shared Slang shader pipeline for DXIL and SPIR-V.
- Amazon Lumberyard Bistro scene: 2.84M triangles, DX12 272.3 FPS, Vulkan 279.4 FPS on RTX 3060.

**Tech:** C++, DirectX 12, Vulkan, Slang
